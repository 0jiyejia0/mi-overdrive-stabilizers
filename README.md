# MI Overclock Addon

NeoForge addon project for Modern Industrialization.

## Versions

- Minecraft: 1.21.1
- Loader: NeoForge 21.1.233
- Java: 21
- Modern Industrialization: 2.4.3
- GuideME: 21.1.16

## Development

Import this folder as a Gradle project in your IDE.

Useful tasks:

```powershell
.\gradlew build
.\gradlew runClient
.\gradlew runServer
```

The first Gradle sync may download Minecraft, NeoForge, mappings, and mod dependencies.
